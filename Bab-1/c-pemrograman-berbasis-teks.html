Bab 1 · Bagian C

Pemrograman Berbasis Teks

Ringkasan Bagian

Bagian ini memperkenalkan Python sebagai bahasa pemrograman dasar menuju AI, mencakup variabel dan empat tipe data dasar (int, float, str, bool), struktur kontrol berupa percabangan (if/elif/else) dan perulangan (for/while), serta fungsi sebagai blok kode yang dapat dipakai ulang. Bagian ditutup dengan contoh chatbot sederhana berbasis aturan sebagai jembatan menuju konsep AI di Bab 3 dan Bab 4.

1. Mengenal Bahasa Pemrograman Python

Python dipilih sebagai bahasa pengantar dalam pembelajaran KKA karena sintaksnya sederhana dan mendekati bahasa manusia sehingga cocok untuk pemula, sekaligus merupakan bahasa yang paling banyak digunakan dalam pengembangan Kecerdasan Artifisial dan Machine Learning saat ini (misalnya untuk membangun chatbot, pengenalan gambar, dan model prediksi). Dengan menguasai dasar Python, peserta didik memiliki modal awal untuk mempelajari AI lebih lanjut di jenjang berikutnya.

2. Variabel dan Tipe Data

Variabel adalah tempat menyimpan data dalam program. Python mengenal beberapa tipe data dasar berikut:

Tipe DataContoh NilaiKegunaan
int (bilangan bulat)17, -5, 2026Menyimpan jumlah, usia, nilai ulangan
float (bilangan desimal)3.14, 75.5Menyimpan nilai rata-rata, suhu, harga
str (teks/string)"Ahmad", "Kelas X"Menyimpan nama, kalimat

nama = "Aisyah"        # str
usia = 16               # int

print(f"{nama} berusia {usia} tahun")

3. Struktur Kontrol

a. Percabangan (Conditional)

Digunakan untuk menjalankan blok kode yang berbeda tergantung pada suatu kondisi, menggunakan if, elif, dan else.

nilai = 85
if nilai >= 90:
    print("Predikat: Sangat Baik")
elif nilai >= 75:
    print("Predikat: Baik")
else:
    print("Predikat: Perlu Bimbingan")

b. Perulangan (Loop)

Digunakan untuk mengulang suatu blok kode tanpa harus menuliskannya berkali-kali, menggunakan for atau while.

# Perulangan for: menampilkan nilai ganjil 1-10
for angka in range(1, 11):
    if angka % 2 != 0:
        print(angka)

# Perulangan while: menghitung mundur
hitung = 5
while hitung > 0:
    print(hitung)
    hitung -= 1
print("Mulai!")

4. Fungsi (Function)

Fungsi adalah blok kode yang diberi nama dan dapat dipanggil berulang kali untuk melakukan tugas tertentu, sehingga kode menjadi lebih rapi dan tidak berulang (istilah kerennya: reusable). Fungsi juga menjadi konsep dasar sebelum peserta didik nantinya memanggil fungsi-fungsi pustaka (library) AI seperti model klasifikasi gambar.

def hitung_luas_persegi_panjang(panjang, lebar):
    luas = panjang * lebar
    return luas

hasil = hitung_luas_persegi_panjang(8, 5)
print(f"Luas persegi panjang: {hasil}")

5. Koneksi dengan AI: Chatbot Sederhana

Struktur kontrol dan fungsi yang baru saja dipelajari sesungguhnya adalah dasar dari cara kerja chatbot berbasis aturan (rule-based chatbot) — nenek moyang dari chatbot AI modern seperti asisten virtual. Perhatikan contoh sederhana berikut:

def chatbot(pesan):
    pesan = pesan.lower()
    if "halo" in pesan:
        return "Halo juga! Ada yang bisa saya bantu?"
    elif "jadwal" in pesan:
        return "Jadwal pelajaran hari ini bisa dilihat di papan info."
    else:
        return "Maaf, saya belum memahami pertanyaan itu."

print(chatbot("Halo, apa kabar?"))

Chatbot AI yang sesungguhnya (seperti asisten virtual) menggunakan model bahasa yang jauh lebih kompleks dan dilatih dari jutaan data, namun logika dasarnya tetap sama: menerima input, memprosesnya melalui serangkaian aturan/perhitungan, lalu menghasilkan output. Memahami dasar ini akan sangat membantu ketika mempelajari AI lebih lanjut di Bab 3 dan Bab 4.
