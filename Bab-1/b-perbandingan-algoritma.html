Bab 1 · Bagian B

Perbandingan Algoritma

Ringkasan Bagian

Bagian ini membahas pengertian algoritma dan ciri-ciri algoritma yang baik, dua cara merepresentasikannya (pseudocode dan flowchart), serta cara membandingkan efisiensi dua algoritma melalui contoh pencarian linear versus pencarian biner. Ditutup dengan pengenalan konsep kompleksitas algoritma (notasi Big-O) yang relevan dalam pengolahan data berskala besar pada sistem AI.

1. Pengertian dan Ciri Algoritma yang Baik

Algoritma adalah urutan langkah logis dan terbatas untuk menyelesaikan suatu masalah. Satu masalah dapat diselesaikan dengan lebih dari satu algoritma, namun tidak semua algoritma sama baiknya. Algoritma yang baik memiliki ciri-ciri berikut:

  • Jelas dan tidak ambigu (unambiguous) — setiap langkah memiliki satu makna pasti.
  • Memiliki input dan output yang terdefinisi dengan jelas.
  • Berhingga (finite) — proses harus berhenti setelah sejumlah langkah tertentu, tidak berjalan selamanya.
  • Efektif — setiap langkah dapat dikerjakan (oleh manusia maupun komputer) dalam waktu yang wajar.
  • Efisien — menggunakan waktu dan sumber daya (memori) seminimal mungkin.

2. Representasi Algoritma

Sebelum dituliskan menjadi kode program, algoritma biasanya digambarkan terlebih dahulu dengan dua cara berikut agar mudah dipahami dan didiskusikan:

BentukCiri-ciriKapan Digunakan
Pseudocode Ditulis seperti bahasa manusia namun terstruktur; tidak terikat sintaks bahasa pemrograman tertentu. Saat merancang logika program secara cepat sebelum menulis kode sesungguhnya.
Flowchart (Diagram Alir) Menggunakan simbol-simbol standar (oval untuk mulai/selesai, persegi panjang untuk proses, belah ketupat untuk keputusan). Saat ingin memvisualisasikan alur logika secara grafis, terutama untuk percabangan dan perulangan.

Contoh Pseudocode: Mencari Bilangan Terbesar

MULAI
Deklarasikan variabel: a, b, c
Masukkan nilai a, b, c
JIKA a > b DAN a > c MAKA
    terbesar = a
LAINNYA JIKA b > c MAKA
    terbesar = b
LAINNYA
    terbesar = c
Tampilkan terbesar
SELESAI

3. Membandingkan Efisiensi Algoritma

Ketika ada lebih dari satu algoritma untuk masalah yang sama, kita perlu membandingkan efisiensinya, terutama dari dua aspek: waktu eksekusi (berapa banyak langkah/operasi yang dibutuhkan) dan penggunaan memori. Sebagai ilustrasi, perhatikan dua algoritma untuk mencari sebuah angka dalam daftar:

Algoritma 1: Pencarian Berurutan (Sequential/Linear Search)

Memeriksa data satu per satu dari awal hingga ditemukan atau sampai data habis.

def pencarian_linear(data, target):
    for i in range(len(data)):
        if data[i] == target:
            return i  # posisi ditemukan
    return -1  # tidak ditemukan

Algoritma 2: Pencarian Biner (Binary Search)

Hanya dapat digunakan jika data sudah terurut. Bekerja dengan membagi dua area pencarian secara berulang, sehingga jauh lebih cepat untuk data yang besar.

def pencarian_biner(data, target):
    kiri, kanan = 0, len(data) - 1
    while kiri <= kanan:
        tengah = (kiri + kanan) // 2
        if data[tengah] == target:
            return tengah
        elif data[tengah] < target:
            kiri = tengah + 1
        else:
            kanan = tengah - 1
    return -1

Untuk mencari satu angka di antara 1.000 data yang sudah terurut, pencarian linear dalam kasus terburuk membutuhkan hingga 1.000 kali pemeriksaan, sedangkan pencarian biner hanya membutuhkan sekitar 10 kali pemeriksaan saja (2¹⁰ = 1024). Inilah sebabnya pencarian biner disebut jauh lebih efisien untuk data besar, meskipun syaratnya data harus sudah terurut lebih dahulu.

Syarat dataTidak harus terurutHarus sudah terurut
Kecepatan pada data besarLambatCepat
Kompleksitas (gambaran kasar)Sebanding jumlah data (n)Sebanding log dari jumlah data (log n)
Kemudahan implementasiSangat mudahSedikit lebih rumit

Istilah Penting: Kompleksitas Algoritma

Notasi Big-O (misalnya O(n) atau O(log n)) adalah cara para ilmuwan komputer menggambarkan seberapa cepat pertumbuhan waktu proses suatu algoritma seiring bertambahnya jumlah data. Semakin kecil pertumbuhannya, semakin efisien algoritma tersebut untuk data berskala besar — hal ini sangat penting dalam sistem AI yang sering mengolah jutaan data sekaligus.
