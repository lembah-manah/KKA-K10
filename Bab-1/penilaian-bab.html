Penilaian Bab 1

Ringkasan Bagian

Halaman ini berisi soal evaluasi Bab 1 dalam tiga bentuk: 5 soal pilihan ganda yang menguji pemahaman konsep dasar, 4 soal esai/uraian yang menguji penjelasan dan penerapan konsep, serta satu proyek mini berpasangan untuk mempraktikkan pemecahan masalah, algoritma, pemrograman, dan debugging sekaligus.

A. Pilihan Ganda

Pilihlah satu jawaban yang paling tepat!

  1. 1. Tahapan berpikir komputasional yang berfokus pada memecah masalah besar menjadi bagian-bagian kecil disebut ....

    • a.Abstraksi
    • b.Dekomposisi
    • c.Algoritma
    • d.Debugging
    • e.Pengenalan pola

  2. 2. Sebuah program dikatakan memiliki algoritma yang baik apabila memenuhi ciri-ciri berikut, kecuali ....

    • a.Berhingga
    • b.Jelas dan tidak ambigu
    • c.Bergantung pada mood programmer
    • d.Efektif
    • e.Efisien

  3. 3. Antara pencarian linear dan pencarian biner, algoritma yang mensyaratkan data harus terurut lebih dahulu adalah ....

    • a.Pencarian linear
    • b.Pencarian biner
    • c.Keduanya
    • d.Tidak keduanya
    • e.Tergantung ukuran data

  4. 4. Perhatikan kode berikut: usia = 16 lalu print(type(usia)). Tipe data dari variabel usia adalah ....

    • a.str
    • b.float
    • c.int
    • d.bool
    • e.list

  5. 5. Kesalahan program yang muncul karena penulisan kode tidak sesuai aturan tata bahasa disebut ....

    • a.Logic error
    • b.Runtime error
    • c.Syntax error
    • d.Value error
    • e.Type error

B. Esai / Uraian

  1. Jelaskan dengan contohmu sendiri (berbeda dari contoh dalam modul) bagaimana empat pilar berpikir komputasional dapat diterapkan untuk memecahkan sebuah masalah sehari-hari.
  2. Buatlah pseudocode untuk menentukan apakah suatu bilangan termasuk bilangan genap atau ganjil.
  3. Jelaskan perbedaan antara syntax error, runtime error, dan logic error, masing-masing disertai satu contoh kode sederhana.
  4. Mengapa keterampilan debugging dianggap sama pentingnya dengan kemampuan menulis kode program? Kaitkan jawabanmu dengan pengembangan sistem Kecerdasan Artifisial.

C. Proyek Mini

Kerjakan secara berpasangan. Buatlah sebuah program Python sederhana (menggunakan percabangan, perulangan, dan minimal satu fungsi) yang menyelesaikan salah satu masalah berikut, kemudian presentasikan alur algoritmanya dalam bentuk pseudocode atau flowchart sebelum menunjukkan kodenya:

  • Program penghitung nilai rapor otomatis berdasarkan beberapa nilai tugas dan ujian.
  • Program kalkulator BMI (Body Mass Index) sederhana dengan kategori hasil.
  • Chatbot sederhana FAQ sekolah (menjawab pertanyaan tentang jadwal, ekstrakurikuler, atau tata tertib).

Rubrik Penilaian Proyek

Ketepatan algoritma (25%), kebenaran dan kerapian kode program (25%), keberhasilan proses debugging apabila terjadi error (25%), serta kejelasan presentasi hasil kepada kelas (25%).
