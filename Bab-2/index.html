Bab 2 · hal. 61–102

Basis Data dan Pengelolaannya

Modul ini disusun agar peserta didik memahami konsep dasar basis data, mampu mengelola data menggunakan perangkat lunak basis data dan bahasa SQL, serta menyadari peran penting data sebagai "bahan bakar" bagi sistem Kecerdasan Artifisial.

Tujuan Pembelajaran Bab 2

Setelah mempelajari Bab 2 ini, peserta didik diharapkan mampu:

  • Menjelaskan konsep data, informasi, dan basis data, serta menjelaskan pentingnya pengelolaan data yang terstruktur.
  • Mengidentifikasi komponen sistem basis data dan menggambarkan model data relasional (tabel, field, record, primary key, foreign key).
  • Merancang skema basis data sederhana menggunakan Entity Relationship Diagram (ERD).
  • Mengenal dan membandingkan berbagai perangkat lunak pengelola basis data (DBMS).
  • Menulis perintah dasar SQL (CREATE, INSERT, SELECT, UPDATE, DELETE) untuk mengelola data pada basis data sederhana.
  • Mengaitkan konsep basis data dengan proses pengumpulan dan pengolahan data (dataset) dalam pengembangan sistem Kecerdasan Artifisial.

Mengapa Bab Ini Penting?

Setiap sistem AI — mulai dari rekomendasi belanja daring, pengenalan wajah, hingga chatbot pintar — dilatih menggunakan data dalam jumlah besar yang tersimpan rapi di dalam basis data. Tanpa data yang terkelola dengan baik, AI tidak dapat belajar apa pun. Memahami cara menyimpan, mengatur, dan mengambil data secara efisien adalah keterampilan dasar sebelum melangkah ke dunia Kecerdasan Artifisial.

Rangkuman Bab 2

  • Basis data adalah kumpulan data yang terorganisasi secara sistematis, digunakan untuk mengatasi masalah redundansi, inkonsistensi, dan sulitnya akses bersama yang terjadi pada penyimpanan data manual.
  • Model data relasional menyusun data dalam bentuk tabel yang terdiri dari field (kolom) dan record (baris), dengan primary key sebagai identitas unik dan foreign key sebagai penghubung antartabel.
  • ERD (Entity Relationship Diagram) digunakan untuk merancang struktur basis data melalui entitas, atribut, dan relasi sebelum basis data benar-benar dibuat.
  • DBMS seperti SQLite, MySQL, dan PostgreSQL adalah perangkat lunak yang digunakan untuk mengelola basis data, dengan SQL sebagai bahasa standar untuk operasi CRUD (Create, Read, Update, Delete).
  • Python dapat digunakan untuk mengakses dan mengelola basis data melalui pustaka sqlite3, menjembatani keterampilan pemrograman pada Bab 1 dengan pengelolaan data pada Bab 2.
  • Basis data yang terkelola dengan baik merupakan fondasi penting bagi dataset yang digunakan untuk melatih model Kecerdasan Artifisial — kualitas data menentukan kualitas hasil AI.
