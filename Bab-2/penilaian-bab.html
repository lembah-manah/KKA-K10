Penilaian Bab 2

Ringkasan Bagian

Halaman ini berisi soal evaluasi Bab 2 dalam tiga bentuk: 5 soal pilihan ganda seputar istilah dan perintah dasar basis data, 4 soal esai/uraian yang menguji perancangan ERD dan penulisan SQL, serta satu proyek mini berpasangan untuk mempraktikkan perancangan ERD, pembuatan tabel, pengisian data, dan query SELECT dengan kondisi.

A. Pilihan Ganda

Pilihlah satu jawaban yang paling tepat!

  1. 1. Kolom pada suatu tabel yang nilainya bersifat unik dan digunakan sebagai identitas setiap baris data disebut ....

    • a.Foreign key
    • b.Primary key
    • c.Field
    • d.Record
    • e.Relasi

  2. 2. Perintah SQL yang digunakan untuk mengambil/menampilkan data dari suatu tabel adalah ....

    • a.INSERT
    • b.UPDATE
    • c.DELETE
    • d.SELECT
    • e.CREATE

  3. 3. Diagram yang digunakan untuk merancang entitas, atribut, dan relasi sebelum basis data dibuat disebut ....

    • a.Flowchart
    • b.ERD
    • c.Pseudocode
    • d.Query
    • e.Skema JSON

  4. 4. Berikut ini yang merupakan DBMS ringan dan tidak memerlukan server terpisah adalah ....

    • a.MySQL
    • b.PostgreSQL
    • c.SQLite
    • d.Oracle
    • e.SQL Server

  5. 5. Dalam konteks pengembangan Kecerdasan Artifisial, data yang buruk dan tidak rapi akan menghasilkan ....

    • a.Model AI yang selalu akurat
    • b.Hasil prediksi yang tetap baik
    • c.Model AI dengan hasil yang buruk (garbage in, garbage out)
    • d.Basis data otomatis rapi
    • e.Tidak berpengaruh sama sekali

B. Esai / Uraian

  1. Jelaskan tiga masalah yang dapat timbul apabila data dikelola secara manual (tanpa basis data), beserta bagaimana basis data mengatasi masalah tersebut.
  2. Rancanglah sebuah ERD sederhana untuk sistem peminjaman alat olahraga di sekolah, lengkap dengan minimal dua entitas dan atributnya.
  3. Tuliskan perintah SQL untuk membuat tabel bernama "buku" dengan kolom kode_buku (primary key), judul, dan stok, kemudian tuliskan perintah untuk menambahkan satu data buku ke dalam tabel tersebut.
  4. Jelaskan keterkaitan antara pengelolaan basis data dengan proses pelatihan model Kecerdasan Artifisial, disertai contoh nyata.

C. Proyek Mini

Kerjakan secara berpasangan. Pilih salah satu tema berikut, lalu rancang ERD sederhana, buat tabelnya menggunakan SQL (boleh melalui SQLite Browser atau kode Python dengan sqlite3), isi dengan minimal 5 data, dan tampilkan hasil query SELECT dengan minimal satu kondisi (WHERE):

  • Basis data perpustakaan sekolah (buku dan status peminjaman).
  • Basis data inventaris alat laboratorium/olahraga sekolah.
  • Basis data pendataan kegiatan ekstrakurikuler siswa.

Rubrik Penilaian Proyek

Ketepatan rancangan ERD (25%), kebenaran struktur tabel dan tipe data (25%), keberhasilan menjalankan perintah SQL CRUD (25%), serta kejelasan presentasi hasil kepada kelas (25%).
