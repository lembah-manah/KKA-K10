Bab 2 · Bagian B

Perangkat Lunak Basis Data

Ringkasan Bagian

Bagian ini mengenalkan DBMS (Database Management System) beserta beberapa contohnya, bahasa SQL dan lima perintah dasarnya (CREATE, INSERT, SELECT, UPDATE, DELETE), cara menggabungkan data antartabel dengan JOIN, serta cara mengelola basis data SQLite menggunakan Python melalui pustaka sqlite3. Ditutup dengan penjelasan alur data dari basis data menjadi dataset yang siap melatih model AI.

1. Mengenal DBMS (Database Management System)

DBMS adalah perangkat lunak yang menjembatani pengguna dengan basis data, memungkinkan proses pembuatan, pembacaan, pengubahan, dan penghapusan data dilakukan dengan aman dan efisien. Berikut beberapa DBMS yang umum digunakan:

DBMSKarakteristikContoh Penggunaan
SQLiteRingan, tidak memerlukan server terpisah, tersimpan dalam satu berkas.Aplikasi skala kecil, aplikasi mobile, latihan pemrograman pemula.
MySQL / MariaDBOpen source, populer untuk aplikasi web, mendukung banyak pengguna sekaligus.Sistem informasi sekolah, toko daring skala menengah.
PostgreSQLOpen source, mendukung fitur lanjutan dan tipe data kompleks, sering dipakai untuk aplikasi berbasis data besar termasuk AI.Aplikasi analitik data dan machine learning.
Microsoft AccessAntarmuka grafis mudah digunakan, cocok untuk pemula dan skala kecil.Basis data kantor atau organisasi kecil.

2. Mengenal Bahasa SQL

SQL (Structured Query Language) adalah bahasa standar yang digunakan untuk berkomunikasi dengan basis data relasional. Dengan SQL, pengguna dapat membuat tabel, memasukkan data, mengambil data, memperbarui data, dan menghapus data. Empat operasi dasar ini sering disingkat CRUD (Create, Read, Update, Delete).

a. Membuat Tabel (CREATE TABLE)

CREATE TABLE siswa (
    nis VARCHAR(10) PRIMARY KEY,
    nama VARCHAR(50),
    kelas VARCHAR(10),
    nilai_kka INT
);

b. Menambahkan Data (INSERT INTO)

INSERT INTO siswa (nis, nama, kelas, nilai_kka)
VALUES ('2026001', 'Ahmad Fauzan', 'X-1', 88);

c. Mengambil Data (SELECT)

-- Menampilkan seluruh data siswa
SELECT * FROM siswa;

-- Menampilkan siswa dengan nilai KKA di atas 85
SELECT nama, nilai_kka FROM siswa WHERE nilai_kka > 85;

-- Mengurutkan data berdasarkan nilai tertinggi
SELECT nama, nilai_kka FROM siswa ORDER BY nilai_kka DESC;

d. Memperbarui Data (UPDATE)

UPDATE siswa
SET nilai_kka = 95
WHERE nis = '2026001';

e. Menghapus Data (DELETE)

DELETE FROM siswa
WHERE nis = '2026003';

Peringatan Penting

Perintah UPDATE dan DELETE tanpa klausa WHERE akan memengaruhi SELURUH baris pada tabel! Selalu periksa kembali klausa WHERE sebelum menjalankan kedua perintah tersebut agar tidak kehilangan data secara tidak sengaja.

3. Menghubungkan Antartabel (JOIN Sederhana)

Kekuatan basis data relasional terletak pada kemampuannya menggabungkan data dari beberapa tabel sekaligus menggunakan perintah JOIN. Misalnya, untuk menampilkan nama siswa beserta nama kelasnya dari dua tabel terpisah (siswa dan kelas):

SELECT siswa.nama, kelas.nama_kelas
FROM siswa
JOIN kelas ON siswa.kode_kelas = kelas.kode_kelas;

4. Mengelola Basis Data dengan Python

Python — bahasa pemrograman yang telah dipelajari pada Bab 1 — dapat digunakan untuk mengakses dan mengelola basis data SQLite melalui pustaka bawaan sqlite3, tanpa perlu instalasi tambahan. Kemampuan ini sangat berguna karena banyak proyek AI ditulis dengan Python, termasuk tahap pengambilan data dari basis data sebelum data tersebut diproses oleh model AI.

import sqlite3

# Membuat koneksi ke basis data (otomatis dibuat jika belum ada)
koneksi = sqlite3.connect('sekolah.db')
cursor = koneksi.cursor()

# Membuat tabel
cursor.execute('''
CREATE TABLE IF NOT EXISTS siswa (
    nis TEXT PRIMARY KEY,
    nama TEXT,
    nilai_kka INTEGER
)
''')

# Menambahkan data
cursor.execute("INSERT INTO siswa VALUES ('2026004', 'Nadia Putri', 90)")
koneksi.commit()

# Mengambil dan menampilkan data
cursor.execute('SELECT * FROM siswa')
for baris in cursor.fetchall():
    print(baris)

koneksi.close()

5. Dari Basis Data Menuju Dataset AI

Dalam proyek Kecerdasan Artifisial, data yang telah rapi tersimpan dalam basis data sering diekspor menjadi dataset (misalnya dalam format CSV) untuk kemudian diolah oleh pustaka pemrosesan data seperti pandas sebelum digunakan melatih model AI. Alur singkatnya dapat digambarkan sebagai berikut:

Data mentah -> Basis Data (disimpan & dikelola dengan SQL)
            -> Dataset (diekspor, mis. file .csv)
            -> Data Cleaning (membersihkan data kosong/tidak valid)
            -> Model AI (proses pelatihan/training)
            -> Prediksi / Keputusan AI

Garbage In, Garbage Out

Tahap paling awal dari alur di atas — merancang dan mengelola basis data dengan benar — yang menentukan seberapa baik kualitas data yang akan diterima oleh model AI. Apabila data yang dimasukkan buruk (tidak rapi, banyak kesalahan), maka hasil AI yang dilatih dari data tersebut juga akan buruk.

Aktivitas Praktik

Instal SQLite Browser (DB Browser for SQLite) atau gunakan situs online seperti sqliteonline.com. Buatlah sebuah tabel bernama "perpustakaan" dengan kolom kode_buku, judul, dan status_pinjam. Masukkan minimal 5 data buku, lalu coba jalankan perintah SELECT untuk menampilkan buku yang berstatus "tersedia" saja.
